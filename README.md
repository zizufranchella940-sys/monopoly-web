# نسخه وب کارتخوان مونوپولی (برای iPhone و هر گوشی دیگر)

یک فایل `index.html` کامل، بدون نیاز به نصب. اطلاعات فقط در مرورگر همان گوشی ذخیره می‌شود.

## انتشار رایگان با GitHub Pages
1. در GitHub یک مخزن جدید **Public** بسازید، مثلاً `monopoly-web`. (مخزن اپ اندروید را Private نگه دارید؛ این مخزن جداست.)
2. فایل‌های `index.html` و `sw.js` را آپلود کنید و Commit بزنید.
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` و پوشه `/ (root)` ← Save.
4. بعد از یکی دو دقیقه آدرس صفحه نمایش داده می‌شود: `https://USERNAME.github.io/monopoly-web/`

## وصل کردن کارت‌ها به iPhone
- در اپ اندروید: تنظیمات ← «آدرس نسخه وب» ← همان آدرس بالا. بعد: بانک کارت‌ها ← «نوشتن مشخصات روی کارت‌ها».
- یا بدون اندروید: در صفحه وب، بانک کارت‌ها ← کارت ← «کپی لینک کارت» و نوشتن لینک با اپ رایگان NFC Tools (Write ← Add a record ← URL).
- iPhone XS و جدیدتر: کارت را بالای پشت گوشی بگیرید و روی اعلان بزنید.
- اندروید با Chrome: در صفحه «روشن کردن NFC» را بزنید.
